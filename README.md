# Neovim Notes

Important custom keybinds:

- `jk` in insert mode: exit to normal mode
- `<leader>\\`: show diagnostics for the current line
- `x`: delete character without yanking it
- `+` / `-`: increment or decrement number under cursor
- `<leader>sa`: select all
- `<leader>fs`: live grep with `fzf-lua`

Opencode:

- `<leader>aa`: ask opencode about current file/selection
- `<leader>as`: open opencode actions
- `<leader>at`: toggle opencode
- `<leader>ar`: send range to opencode
- `<leader>aR`: send current line to opencode

Buffers:

- `<Tab>`: next buffer
- `<S-Tab>`: previous buffer
